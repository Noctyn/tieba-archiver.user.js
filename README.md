# 贴吧存档助手（TiebaArchiver 浏览器版）

在贴吧帖子页抓取主题帖、全部楼层与楼中楼，导出为完整 JSON 或用于 AI 分析的 Lite 文本。

## 特性

- **完整结构抓取**：采用与 TiebaArchiver 相同的客户端 Protobuf 接口，抓取主题帖、全部楼层与楼中楼。
- **两种导出格式**：
  - **JSON**：单文件结构对应 threads 目录数据（thread、forum、post 表、user 表），保留原始链接与元数据。
  - **Lite 文本**：精简结构低 Token 消耗，适合直接喂给 AI / 大模型分析与总结。
- **灵活控制**：支持随时取消并保存已抓取部分、调整并发与抓取页数上限、进度条实时显示。

## 安装与使用

1. 确保浏览器已安装 Tampermonkey（油猴）或兼容的脚本管理器。
2. 安装 `tieba-archiver.user.js`。
3. 登录并打开任意百度贴吧帖子页（`https://tieba.baidu.com/p/*`）。
4. 点击导航栏中的「导出」按钮（或右下角浮动入口），选择格式并开始抓取。
